# LovePilot AI V0.9

V0.9 adds an AstrBot Personal WeChat bridge based on the documented Tencent iLink Bot channel. Start with `ILINK_ASTRBOT_SETUP.md`.

**Not a personal-account takeover tool:** this creates a separate AI bot conversation. It cannot read or reply inside the user's existing one-to-one chats with other WeChat friends.

Start with auto reply disabled. A participant must send `/start` to opt in. `/pause` revokes consent; `/forget` deletes that conversation's stored data.

See `README.md` for the LovePilot backend and `V09_UPGRADE.md` for validation and limitations.


## V1.0 notes
See `V10_UPGRADE.md`, `.env.example`, and `docs/V10_ACCEPTANCE.md`. Automatic reply remains disabled by default.
